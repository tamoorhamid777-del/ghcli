# Support

Thank you for using `ghcli`! Here's how to get help.

## 📖 Documentation

Before asking for help, please check:

- **[README.md](README.md)** — Installation, quick start, and command reference
- **[CHANGELOG.md](CHANGELOG.md)** — What's new in each version
- **[Troubleshooting section](README.md#-troubleshooting)** — Common issues and fixes

## 🐛 Found a Bug?

Please [open a bug report](https://github.com/your-org/ghcli/issues/new?template=bug_report.md) on GitHub Issues.

Include:
- Your OS and Python version
- `ghcli` version (`ghcli --version`)
- Steps to reproduce
- Expected vs. actual behavior

## 💡 Feature Request?

Please [open a feature request](https://github.com/your-org/ghcli/issues/new?template=feature_request.md) on GitHub Issues.

## 💬 General Questions

For general questions and discussions:

- **[GitHub Discussions](https://github.com/your-org/ghcli/discussions)** — Ask questions, share ideas, show off what you've built

## 🔒 Security Issues

**Do NOT open a public issue for security vulnerabilities.**

Please read our [Security Policy](SECURITY.md) and report vulnerabilities privately.

## ⏱️ Response Times

This is an open-source project maintained by volunteers. We aim to:

- Respond to bug reports within **3–5 business days**
- Respond to feature requests within **1–2 weeks**
- Merge security fixes within **14 days** of confirmation

We appreciate your patience and understanding!

## 🤝 Want to Help?

The best way to get faster support is to contribute! See [CONTRIBUTING.md](CONTRIBUTING.md)
to learn how to submit bug fixes, features, and documentation improvements.
